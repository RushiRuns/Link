# Data Model: Link LAN Messenger MVP

**Date**: 2026-07-27
**Feature**: specs/001-lan-messenger-mvp/spec.md
**Research**: specs/001-lan-messenger-mvp/research.md

## Entities

### 1. LocalIdentity

Represents the running user's own persistent identity. Created once on first launch, persisted via `electron-store` + OS `safeStorage`.

| Field | Type | Notes |
|-------|------|-------|
| `deviceId` | `string` (UUID v4) | Generated on first launch. Immutable. Unique per install. |
| `displayName` | `string` (1–64 chars) | Set by user on first launch. Editable in settings. |
| `privateKey` | `Uint8Array` (32 bytes) | Curve25519 private key. Encrypted via OS keychain. Never leaves device. |
| `publicKey` | `Uint8Array` (32 bytes) | Curve25519 public key. Advertised during discovery and Noise handshake. |
| `publicKeyFingerprint` | `string` | Truncated hex of SHA-256(publicKey). Display-only. |
| `appVersion` | `string` (semver) | Advertised during connection handshake for version compatibility check. |

**State transitions**: None — LocalIdentity is set on first launch and mutated only via settings (displayName).

---

### 2. Peer

Represents a remote user discovered on the LAN. Stored in the SQLite `peers` table (encrypted via SQLCipher).

| Field | Type | Notes |
|-------|------|-------|
| `id` | `string` (UUID v4) | Peer's own deviceId, received during handshake. Primary key. |
| `displayName` | `string` | Last known display name. Updated on each connection. |
| `publicKey` | `Uint8Array` (32 bytes) | Stored after first TOFU acceptance. Used for all subsequent Noise handshakes. |
| `publicKeyFingerprint` | `string` | Derived from publicKey. Displayed in peer profile view. |
| `appVersion` | `string` (semver) | Received during handshake. Used for compatibility enforcement. |
| `status` | `enum` | `online` \| `offline` \| `version_mismatch` |
| `networkAddress` | `string` | IP address on the LAN. Ephemeral — not persisted between sessions. |
| `listeningPort` | `number` | TCP port for direct connection. Ephemeral. |
| `lastSeen` | `Date` | Timestamp of last successful keepalive/connection. Persisted. |
| `isKnown` | `boolean` | `true` after first successful TOFU handshake. Used to distinguish new vs returning peers. |

**State transitions**:
```
discovered → connecting → online → offline
discovered → version_mismatch (terminal for session)
online → offline (keepalive timeout or graceful disconnect)
offline → online (reconnection)
```

---

### 3. Conversation

A 1-to-1 messaging session between the local user and one peer. Session-scoped (in-memory); not persisted between app restarts.

| Field | Type | Notes |
|-------|------|-------|
| `id` | `string` | `conv_${localDeviceId}_${peerDeviceId}` — deterministic, stable per peer pair. |
| `peerId` | `string` | References `Peer.id`. |
| `messages` | `Message[]` | Ordered array, newest last. In-memory only. |
| `unreadCount` | `number` | Count of messages received since user last viewed this conversation. |
| `createdAt` | `Date` | Session start time. |

---

### 4. Group

A named collection of peers for multi-party messaging. Session-scoped (in-memory); not persisted between app restarts. Membership distributed to all members at creation.

| Field | Type | Notes |
|-------|------|-------|
| `id` | `string` (UUID v4) | Generated by creator. Shared with all members at creation. |
| `name` | `string` (1–64 chars) | User-defined group name. Set at creation. |
| `creatorId` | `string` | `deviceId` of the peer who created the group. Informational only after creation. |
| `members` | `GroupMember[]` | Full membership list. Distributed to all members at creation time. |
| `messages` | `Message[]` | Ordered array. In-memory only. |
| `isActive` | `boolean` | `false` when all members are offline. |
| `createdAt` | `Date` | Session timestamp. |

#### GroupMember (embedded in Group)

| Field | Type | Notes |
|-------|------|-------|
| `peerId` | `string` | References `Peer.id`. |
| `displayName` | `string` | Snapshot at time of group creation. |
| `publicKey` | `Uint8Array` | Used to establish encrypted connections to this member. |
| `status` | `enum` | `online` \| `offline` — derived from active connections. |

---

### 5. Message

A single text message within a Conversation or Group. Session-scoped; in-memory only.

| Field | Type | Notes |
|-------|------|-------|
| `id` | `string` (UUID v4) | Generated by sender. |
| `conversationId` / `groupId` | `string` | Exactly one of these is set, never both. |
| `senderId` | `string` | `deviceId` of sender. |
| `senderName` | `string` | Snapshot of display name at send time. |
| `content` | `string` | Plaintext content (post-decryption). Never stored in ciphertext form. |
| `timestamp` | `Date` | Sender's local clock at send time. |
| `deliveryStatus` | `enum` | `sending` \| `sent` \| `delivered` \| `failed` |

**Delivery status transitions**:
```
sending → sent (message dispatched to peer's TCP socket)
sending → failed (send error or peer offline)
sent → delivered (delivery ACK received from recipient's app)
```
No `read` state. No read receipts (FR-016).

---

### 6. FileTransfer

A file being sent or received. Session-scoped (not persisted between restarts), but the completed file is saved to disk.

| Field | Type | Notes |
|-------|------|-------|
| `id` | `string` (UUID v4) | Generated by sender. |
| `direction` | `enum` | `outgoing` \| `incoming` |
| `peerId` | `string` | The other party in the transfer. |
| `groupId` | `string \| null` | Set if this is a group file send. |
| `fileName` | `string` | Original filename. |
| `fileSizeBytes` | `number` | Total file size in bytes. |
| `mimeType` | `string` | Best-effort MIME type from extension. |
| `status` | `enum` | `pending_accept` \| `transferring` \| `completed` \| `declined` \| `failed` \| `cancelled` |
| `bytesTransferred` | `number` | Updated as chunks arrive/send. Used for progress indicator. |
| `savePath` | `string \| null` | Absolute path where file is saved on recipient's device. Null for sender. |
| `startedAt` | `Date \| null` | Set when transfer begins (after acceptance). |
| `completedAt` | `Date \| null` | Set on completion or failure. |

**Chunked transfer**: Files split into 64 KB chunks over the encrypted TCP connection. Chunks are individually encrypted; failure of one chunk fails the whole transfer (no partial resume in MVP).

---

### 7. Call

A real-time voice or video session between two peers via WebRTC. Session-scoped.

| Field | Type | Notes |
|-------|------|-------|
| `id` | `string` (UUID v4) | Generated by initiator. |
| `initiatorId` | `string` | `deviceId` of calling peer. |
| `peerId` | `string` | The other party. |
| `mediaType` | `enum` | `voice` \| `video` |
| `status` | `enum` | `ringing` \| `active` \| `ended` \| `declined` \| `failed` |
| `startedAt` | `Date \| null` | Set when both parties connected. |
| `endedAt` | `Date \| null` | Set on termination. |

**Signaling**: SDP offer/answer and ICE candidates exchanged over the existing Noise-encrypted TCP connection (no external STUN/TURN/signaling server).

---

### 8. KnownPeers (Persisted Registry)

Persisted in the SQLite database (SQLCipher encrypted). The in-memory `Peer` entity is hydrated from this on startup. Updated whenever a peer is seen or updated.

Maps to the `peers` database table. Fields match `Peer` entity minus ephemeral fields (`networkAddress`, `listeningPort`, `status`).

## Persistence Boundary Summary

| Entity | Persisted? | Storage |
|--------|-----------|---------|
| LocalIdentity | ✅ Yes | `electron-store` + `safeStorage` (OS keychain) |
| KnownPeers | ✅ Yes (name, publicKey, lastSeen) | SQLite + SQLCipher |
| Peer (runtime) | ❌ In-memory | — |
| Conversation | ❌ In-memory | — |
| Group | ❌ In-memory | — |
| Message | ❌ In-memory | — |
| FileTransfer metadata | ❌ In-memory | — |
| File contents (received) | ✅ Disk | OS filesystem (user-chosen path) |
| Call | ❌ In-memory | — |

## Validation Rules

- `displayName`: 1–64 characters, non-empty after trimming whitespace.
- `deviceId`: Must be a valid UUID v4; immutable after creation.
- `Message.content`: Non-empty string; max 10,000 characters (UI-enforced).
- `Group.members`: Minimum 2 members (creator + at least 1 other). Maximum: not specified for MVP; practical limit ~20 (mesh connection count).
- `FileTransfer.fileSizeBytes`: No upper limit enforced by the protocol; chunked transfer handles arbitrary size (FR-005).
- `Peer.appVersion`: Must match local app's major.minor version; patch differences are allowed. Mismatch → `version_mismatch` status, connection refused (FR-019).
