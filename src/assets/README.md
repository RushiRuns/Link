# Assets Directory

This directory stores static media assets used across the application:

- **`images/`**: Logos, avatars, placeholders, background graphics.
- **`audio/`**: Sound effects, notification chimes, call ringtones.
- **`videos/`**: Video clips, demo media, tutorial assets.
- **`icons/`**: Custom SVG icons or graphics.

### How to use in React/Vite:
```tsx
import logo from './assets/images/logo.png';
import ringtone from './assets/audio/ringtone.mp3';
```
